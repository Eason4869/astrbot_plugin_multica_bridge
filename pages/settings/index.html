工作模式

每个群、每个私聊，各自决定何时开始工作。

启用工作模式

关闭后暂停转发，已开启的聊天仍可用 /multica exit 退出。

默认智能体

留空时自动选择唯一智能体；多个智能体可在聊天中按编号选择。

回复始终带有【来自 Multica｜工作模式】前缀。群聊仅开启者的文字转发，群外消息不受影响；首版支持文字。

当前工作会话

还没有工作会话在 QQ 群或私聊发送 /multica，即可在这里看到。
退出只恢复该聊天的普通机器人，不停止 Multica 已接收的后台任务。

连接与访问

已有 URL、Token 和工作区会继续保留，修改后自动保存。

启用 Multica 桥接

已保存的 Token 仅显示脱敏值，留空不会清除。
验证 URL 和 Token 后，自动读取可选工作区。
在 Multica 管理

工作区和项目为全局默认值。变更后旧绑定暂停，请在受影响聊天发送 /multica new；切换工作区会清空旧项目。

Multica 放行用户名单

UID / UMO

群聊与私聊统一授权。每行一项，可混填；匹配任意一项即可使用。留空时无人可用。

01 · UID用户QQ号

该用户可在所有群聊和私聊使用。

02 · FriendMessage机器人ID:FriendMessage:用户QQ号

仅允许该用户通过 机器人ID 私聊使用，不放行群聊。

03 · GroupMessage机器人ID:GroupMessage:群号

允许 机器人ID 所在的该群所有成员使用指令。

群聊进入工作模式后，仅开启者的文字转发给 Multica；其他群友继续使用 AstrBot。工作回复在群内可见。

未获放行时回复：您没有使用Multica的权限，请联系管理员获取使用资格

谁能开始工作？

在 AstrBot「指令管理」中设置 multica enter 的权限，可限制谁能开启模式和发送工作消息。

工作操作使用当前 Token 所属账号的权限。多人共用时，请只开放给可信会话。

指令与高级设置

工作模式不需要重复指令；下面的命令用于控制会话。

/multica

进入或恢复当前窗口的工作模式

/multica exit

退出模式，恢复普通机器人

/multica new

新建对话，保留旧对话

/multica agent [编号或ID]

选择智能体并开启新对话

/multica stop

停止执行，保持工作模式

/multica status

查看当前模式与执行状态

/multica help

查看帮助

普通模式中的自然语言控制与管理命令

启用自然语言控制

普通模式识别进入工作模式、收件箱查询和 Issue 草稿，写入前需本人确认。

规则失败时使用 LLM

普通模式可用 AstrBot 模型识别管理意图。工作模式始终直接连接 Multica。

原有 issue、inbox、workspace、project 命令继续可用。发送 /multica help 查看说明。
