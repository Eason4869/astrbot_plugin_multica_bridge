工作模式

每个群、每个私聊，各自决定何时开始工作。

启用工作模式

关闭后暂停转发，已开启的聊天仍可用 /multica exit 退出。

默认智能体

留空时自动选择唯一智能体；多个智能体可在聊天中按编号选择。

回复始终带有【来自 Multica｜工作模式】前缀。同一群内成员共用对话，群外消息不受影响；首版支持文字。

谁能开始工作？

在 AstrBot「指令管理」中设置 multica enter 的权限，可限制谁能开启模式和发送工作消息。

工作操作使用当前 Token 所属账号的权限。多人共用时，请只开放给可信会话。

指令与高级设置

工作模式不需要重复指令；下面的命令用于控制会话。

/multica

进入或恢复当前窗口的工作模式

/multica exit

退出模式，恢复普通机器人

/multica new

新建对话，保留旧对话

/multica agent <ID>

选择智能体并开启新对话

/multica stop

停止执行，保持工作模式

/multica status

查看当前模式与执行状态

普通模式中的自然语言控制与管理命令

启用自然语言控制

仅在普通模式识别建 Issue、切换项目等管理操作。

规则失败时使用 LLM

普通模式可用 AstrBot 模型识别管理意图。工作模式始终直接连接 Multica。

原有 issue、inbox、workspace、project 命令继续可用。发送 /multica help 查看说明。
