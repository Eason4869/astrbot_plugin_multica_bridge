Multica 桥接设置

配置 Multica 平台连接参数，修改后自动保存热生效

连接配置

启用 Multica 桥接
关闭后插件完全停止
Multica API 地址
例如 http://your-server:8080
认证 Token
Multica 平台的 API 认证 Token
工作区 ID
可选，留空自动从 API 获取（推荐只填上面两项即可）
项目 ID
可选，指定后数据关联到特定项目

会话过滤

控制插件在哪些群聊/私聊中生效，支持黑名单、白名单和关闭三种模式。

群聊过滤模式
黑名单：排除指定群 / 白名单：仅指定群可用 / 关闭：不限制
群聊 ID 列表（每行一个）
私聊过滤模式
黑名单：排除指定用户 / 白名单：仅指定用户可用 / 关闭：不限制
用户 ID 列表（每行一个）

指令说明

在允许的群聊/私聊中发送以下指令即可操作 Multica：

/multica help显示帮助信息
/multica status检查 Multica 连接状态
/multica issue create <标题> [--desc 描述]通过 API 新建 Issue（不依赖本机 CLI）
