会话过滤

控制插件在哪些群聊 / 私聊中生效
群聊过滤模式
黑名单：排除指定群 · 白名单：仅指定群可用 · 关闭：不限制
群聊 ID 列表（每行一个）
私聊过滤模式
黑名单：排除指定用户 · 白名单：仅指定用户可用 · 关闭：不限制
用户 ID 列表（每行一个）
💡 权限提醒：可在 AstrBot「指令管理」中将本插件主指令 /multica 设为 仅管理员，实现 ChatOps 指令的权限回收。
💬

指令说明

在允许的群聊 / 私聊中发送以下指令操作 Multica
/multica help显示帮助信息
/multica status检查连接与 Token 状态
/multica issue create <标题> [--desc 描述]新建 Issue（不依赖本机 CLI）
/multica workspace list列出可访问的工作区
/multica workspace select <id|slug>切换当前工作区（持久化）
/multica workspace create <名称> [--slug ..] [--desc ..]创建工作区
/multica project list列出当前工作区的项目
/multica project select <id>切换当前项目（持久化），新建 Issue 默认进入所选项目
/multica project create <标题> [--desc ..]创建项目
/multica inbox [数量] [open|done]收件箱：最近 Issue 及进展（可只看未完成/已完成）
