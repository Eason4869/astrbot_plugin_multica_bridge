会话过滤

控制插件在哪些群聊 / 私聊中生效
群聊过滤模式
黑名单：排除指定群 · 白名单：仅指定群可用 · 关闭：不限制
群聊 ID 列表（每行一个）
私聊过滤模式
黑名单：排除指定用户 · 白名单：仅指定用户可用 · 关闭：不限制
用户 ID 列表（每行一个）
💡 权限提醒：可在 AstrBot「指令管理」中把每条指令分别设为「仅管理员」， 例如收紧 workspace create / project create 给管理员，而把 inbox 放开给成员。
💬

指令说明

在允许的群聊 / 私聊中发送以下指令操作 Multica
/multica显示指令树
/multica help显示帮助信息
/multica status检查连接、当前工作区与项目
/multica issue create <标题> [选项]新建 Issue（支持 --desc/--priority/--status 等）
/multica workspace list列出可访问的工作区
/multica workspace select <id|slug>切换当前工作区（持久化）
/multica workspace create <名称> [选项]创建工作区
/multica project list列出当前工作区的项目
/multica project select <id>切换当前项目（持久化）
/multica project create <标题> [--desc ..]创建项目
/multica inbox [数量] [open|done]收件箱：最近 Issue 及进展
